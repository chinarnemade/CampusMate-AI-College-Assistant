# CampusMate V2
Upgraded existing Flask + Ollama project.

Features: glass UI, light/dark mode, login/signup, SQLite chat history,
multiple conversations, Assignment Coach with subject selection, and local Ollama AI.

Run in the existing project environment:
```powershell
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000
